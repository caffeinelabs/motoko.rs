# AGENTS.md

Motoko tooling (lexer, parser, and a partial interpreter) implemented in Rust.

## Build, test, format, lint

The repo is a Cargo workspace. CI (`.github/workflows/rust.yml`) uses the
**nightly** toolchain with the `rustfmt` and `clippy` components, then runs:

```
cargo build --verbose
cargo test --verbose
```

Format with `cargo fmt` and lint with `cargo clippy` (both require nightly, as
installed in CI).

The `mo-rs` binary is gated behind the `exe` feature; build or run it with
`cargo run -p motoko --features exe --bin mo-rs`.

## License check

`.github/workflows/license.yml` runs `cargo-deny` with
`check bans licenses sources`. Dependencies must satisfy these checks to pass CI.

## Benchmarks

The benchmark target lives at `crates/motoko/benches/benchmark.rs` (Criterion,
`harness = false`) and is run in CI (`.github/workflows/bench.yml`) on pull
requests. Files under `crates/motoko/_benches/` are not wired into the build.

## Layout

- `crates/motoko/` — main library (`src/lib`) and the `mo-rs` binary (`src/bin`).
- `crates/motoko_proc_macro/` — procedural macros used by the library.
- `node/` — a Node script (`generate.js`, run via `npm run generate`) that
  regenerates package data; see below.
- `submodules/` — git submodules `motoko` and `motoko-base`; run
  `git submodule update --init` before generating packages.
- `docs/` — grammar reference.

## Generated files (do not hand-edit)

- `crates/motoko/src/lib/parser.lalrpop` is compiled at build time by
  `build.rs` (LALRPOP); the generated parser is produced during `cargo build`.
- `crates/motoko/src/packages/prim.mo` and
  `crates/motoko/src/packages/*.json` are generated by `node/generate.js` from
  the `submodules/motoko` and `submodules/motoko-base` sources. Edit the
  generator or sources, then rerun `npm run generate` in `node/`, rather than
  editing these files directly.

## Feature flags

Library default features are `parser` and `to-motoko`. Other features:
`exe`, `serde-paths`, `reflection`, `value-reflection`, `core-reflection`.
