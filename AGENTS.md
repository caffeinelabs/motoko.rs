# AGENTS.md

Motoko tools for Rust: a library for lexing, parsing, and interpreting the Motoko language.

## Build, test, lint, format

Run from the repository root (a Cargo workspace):

- Build: `cargo build`
- Test: `cargo test`
- Format: `cargo fmt`
- Lint: `cargo clippy`
- Benchmarks: `cargo bench` (Criterion; the harness lives in `crates/motoko/benches/benchmark.rs`)

CI (`.github/workflows/rust.yml`) builds and tests on the Rust **nightly** toolchain
with the `rustfmt` and `clippy` components. The `license.yml` workflow runs
`cargo-deny check bans licenses sources`; dependency, license, or source changes
can fail this check.

The REPL binary `mo-rs` requires a feature flag: `cargo run -p motoko --features exe --bin mo-rs`.

## Layout

- `crates/motoko` — the main library (`motoko`) and the `mo-rs` binary.
- `crates/motoko_proc_macro` — procedural macros for compile-time Motoko expressions.
- `node/` — a Node script (`generate.js`) that regenerates bundled Motoko packages.
- `submodules/` — git submodules `motoko` and `motoko-base` (upstream sources).
- `docs/grammar.txt` — language grammar reference.
- `crates/motoko/_benches/` — standalone benchmark sources (note the leading underscore;
  the active benchmark harness is `crates/motoko/benches/`).

## Conventions and gotchas

- Initialize submodules before generating packages: `git submodule update --init`.
  `node/generate.js` reads `submodules/motoko/src/prelude/prim.mo`.
- Generated files in `crates/motoko/src/packages/` (`prim.mo`, `base.json`,
  `base-test.json`, `matchers.json`) are produced by `node/generate.js`
  (run `npm install && npm run generate` in `node/`). Do not hand-edit them.
- The parser source `crates/motoko/src/lib/parser.rs` is generated by LALRPOP from
  `src/lib/parser.lalrpop` at build time (`build.rs`) and is gitignored. Do not hand-edit it.
- `Cargo.lock` and `/target/` are gitignored.
- Default crate features are `parser` and `to-motoko`; the `motoko` crate exposes
  additional optional features (`exe`, `reflection`, `serde-paths`, etc.).
